# Theme

**North Star:** look native to VS Code; keep colour for what the data means.

## Interface colours

*To be filled in Phase 1.* Interface colours come only from VS Code theme tokens (`--vscode-*` variables), so Debrief follows the analyst's theme, including high contrast (CON-06, NFR-13). The web build supplies the same variables. An automated check for hard-coded interface colours arrives in Phase 1 (DEV-10).

## Data colours

*To be filled in Phase 1, reviewed by analysts.* Data colours (track conventions such as red and blue forces, sensor and annotation colours) are separate from the theme and do not change with it (DEV-07). Version 1 starts from legacy Debrief's conventions.

## Contrast and accessibility

*To be filled in Phase 1.* Data colours shall remain distinguishable on light, dark and high-contrast themes (NFR-13).
