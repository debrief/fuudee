# Check overrides

How quality checks advise, and how an analyst overrides them.

*The model, its sequence diagram and its reference implementation are written in Phase 2. Version 0 gathers the requirements it must satisfy.*

## Requirements cited

| SRD | Requirement |
| --- | --- |
| PRN-08 | The analyst owns the data: checks advise, the analyst may override, and overrides are recorded. |
| TL-16 | Checks are tools bound to lifecycle events. |
| TL-17 | A failed pre-save check warns and offers an override; saving anyway is recorded. |
| EXT-15 | Content not imported is listed, never silently dropped. |
