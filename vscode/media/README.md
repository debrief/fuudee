# Media

- `debrief.svg`: the activity bar icon. It is monochrome, so VS Code colours it to match the theme.
- `land.geojson`: land areas for the reference map. It comes from Natural Earth's 1:50m land polygons (public domain, <https://www.naturalearthdata.com>), with coordinates rounded to 0.001°. That is coarse: coastlines can be several kilometres out at exercise scale. Proper reference charts arrive with the reference tile service (decision log, 25 September).
